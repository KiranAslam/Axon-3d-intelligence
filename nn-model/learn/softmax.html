What softmax does

The final layer produces ten raw scores. Softmax converts those scores into normalized values that can be compared as a probability distribution over the ten digit classes.

Logits are not probabilities

The output layer first produces one raw score for each class. These scores can be positive or negative and are not constrained to add up to one.

The softmax formula

P(digit i) = exp(zᵢ) / Σ exp(zⱼ)

The exponential function makes larger logits contribute more strongly, and the denominator normalizes all ten outputs so they sum to one.

Reading the result

If one class has a much larger probability than the others, the model is strongly favoring that class under the current input. A flatter distribution means the model is less decisive.

A useful caution

A softmax value should not automatically be treated as a perfectly calibrated statement of real-world certainty. It is the model's normalized output for the classes it was trained to distinguish.
