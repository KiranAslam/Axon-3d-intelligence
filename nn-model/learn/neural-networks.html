Foundations

What is a neural network?

A neural network is a parameterized function made from connected computational units arranged in layers. In AXON, those layers transform a 28×28 drawing until the model produces scores for ten digit classes.

Neurons and layers

A neuron receives numerical values, combines them using learned weights and a bias, and produces an activation. A layer contains many such neurons. Stacking layers lets the model transform the input more than once.

Why multiple layers?

A single linear transformation can only represent a limited family of relationships. Nonlinear activations such as ReLU allow successive layers to build more useful representations from earlier ones.

How AXON is arranged

The current visualization uses 784 input values, hidden layers of 128 and 64 neurons, and 10 output neurons for digits 0–9. The architecture is intentionally small enough to visualize while still demonstrating the main ideas of a feedforward network.

What to observe in the visualizer

Draw a digit, inspect the layers, and compare the output probabilities. The point is not only to see which digit wins, but to connect the visible structure with the computation described above.
