Hidden layers

Weights, bias and ReLU

Hidden layers transform incoming values using learned parameters. Three terms are especially important in the AXON model: weights, bias and ReLU.

Weights

A weight controls how strongly one incoming value contributes to a neuron's weighted sum. During training, the model learns useful values for these parameters.

Bias

A bias is an additional learned value added to the weighted sum. It gives the neuron another degree of freedom when fitting patterns.

z = (w₁·x₁ + w₂·x₂ + ... + wₙ·xₙ) + bias

ReLU

AXON applies ReLU in the hidden layers. Its rule is simple:

ReLU(z) = max(0, z)

Negative values become zero while positive values remain. The important teaching point is that ReLU introduces nonlinearity, which makes a stack of layers more expressive than repeated linear transformations alone.

Try it

Select a neuron in the visualizer where supported, inspect its values, then change the drawing. Comparing responses makes the abstract parameter concepts easier to connect to the live model.
