How 28×28 pixels become 784 inputs

A handwritten digit starts as a visual pattern, but the neural network receives numbers. AXON makes this conversion explicit so learners can see where the 784 inputs come from.

The 28×28 grid

The drawing area is represented as a grid with 28 rows and 28 columns. Multiplying those dimensions gives 784 positions: 28 × 28 = 784.

Pixels become numbers

Each pixel contributes a numerical value representing its intensity. A blank or weakly drawn position contributes a lower value, while a stronger stroke contributes a higher value.

Flattening the image

For a dense feedforward network, the two-dimensional grid can be flattened into a one-dimensional vector of 784 values. That vector becomes the input to the first layer.

Why this matters

This is the first conceptual bridge between an image and machine learning: the model does not receive a picture as a human does. It receives a structured collection of numbers.
