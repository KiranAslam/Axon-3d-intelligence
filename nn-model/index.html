01 · Architecture

From 784 pixels to one prediction

The network is a compact feedforward model. Each stage transforms the representation before passing it forward.

Input layer

784 neurons

One value for every pixel in the 28×28 drawing grid. The image becomes numerical input for the network.

Hidden layers

128 → 64 neurons

Learned weights, biases and ReLU activations transform the input into increasingly compact representations.

Output layer

10 classes

Ten output neurons represent digits 0–9. Softmax turns the final scores into a probability distribution.

1

The input layer

Your drawing is represented as a 28×28 grid, giving 784 numerical values. The network receives numbers rather than a human-style visual understanding of the picture.

That conversion is the bridge between an image and machine-learning computation.

2

Weights, bias and activation

Every neuron receives values from the previous layer. Each connection has a learned weight, and each neuron has a bias. Together they produce a weighted sum.

z = (w₁·x₁ + w₂·x₂ + ... + wₙ·xₙ) + bias activation = ReLU(z) = max(0, z)

ReLU removes negative values and introduces non-linearity, allowing stacked layers to learn richer patterns than a purely linear transformation.

3

The output layer

The final layer contains ten neurons corresponding to digits 0 through 9. Their raw scores, called logits, are converted into probabilities using softmax.

P(digit i) = exp(zᵢ) / Σ exp(zⱼ)

The highest-probability class becomes the displayed prediction.

02 · Training

How the model learns

The interactive application uses trained parameters rather than inventing connection values during the demonstration.

This project uses a neural network trained with TensorFlow/Keras. Its trained parameters are used by the Unity WebGL application to process a drawing and calculate the model's response in the browser.

03 · Interaction

Learn by exploring

The visualizer is designed to make an abstract forward pass easier to inspect.

  • Draw a digit and observe the model's response.
  • Select neurons to inspect values, biases and connections where supported by the visualization.
  • Rotate, pan and zoom the 3D scene to understand how the layers are arranged.
  • Compare outputs by changing the input and observing how the probability distribution changes.
04 · Technology

How this model is built

The website provides the learning context while the Unity application provides the interactive 3D experience.

The project uses Unity WebGL for the browser-based visualization, with matrix operations, ReLU and softmax calculations performed in C# inside the Unity application.
