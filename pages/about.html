About AXON 3D Intelligence

AXON is an interactive educational project designed to help learners connect machine-learning mathematics with something they can actually see and manipulate.

Purpose

AXON turns a handwritten-digit classifier into an interactive visual experience. The project focuses on the relationship between input pixels, neural-network layers, parameters, activations and output probabilities.

Current model

The current experience focuses on a feedforward neural network for handwritten-digit classification, with a 28×28 input and ten output classes. The interactive application is delivered through Unity WebGL.

Learning-first design

The site is intentionally split between an interactive visualizer and focused educational guides. Visitors can experiment first, then read the explanation of the computation they just observed.

Project ownership and contact

AXON 3D Intelligence is the project name used throughout this site. For questions, feedback, collaboration ideas or technical reports, use the Contact page.

Technology

The visualizer uses Unity WebGL. The surrounding site is a static HTML/CSS/JavaScript experience designed to be fast, readable and easy to navigate.
