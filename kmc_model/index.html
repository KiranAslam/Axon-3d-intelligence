K-Means Interactive Visualizer
01 · Architecture

From numeric features to cluster assignments

K-Means groups numeric points by assigning each one to its nearest centroid. Most datasets use two features; image color quantization uses red, green and blue values.

Input

Features or RGB

Most datasets use two numeric features shown across the X and Z axes. Sampled image pixels use three values: red, green and blue.

Centroids

User-selected K

Each centroid represents one cluster. Choose K to set how many groups the algorithm will form.

Output

Cluster assignments

Every point receives a cluster ID and the scene colors it by group. IDs are not known categories or predictions.

1

The input data

K-Means operates on numeric coordinates, not names or descriptions. The customer segmentation dataset uses income and spending behavior; the Iris dataset uses petal measurements.

Most datasets use two dimensions underneath and are arranged in the 3D scene for viewing. Image color quantization instead represents each sampled pixel with its R, G and B values.

2

Distance and assignment

For each point, the algorithm measures its distance to every centroid and assigns it to the nearest one. The visualizer offers Euclidean, Manhattan and Cosine distance; each can produce different groupings.

Euclidean distance: d(x, c) = sqrt(sum((x[j] - c[j])^2))

Euclidean distance measures straight-line separation. Manhattan and Cosine compare points in different ways.

3

Centroid updates and convergence

After assignment, each centroid is recalculated using a rule that matches the selected distance: the mean for Euclidean, the coordinate-wise median for Manhattan, and a normalized mean direction for Cosine.

Assignment and update steps repeat until total centroid movement falls below 0.001 or the default limit of 100 iterations is reached.

Initialization detail: K-Means++ is available with Euclidean distance. With Manhattan or Cosine, this implementation uses random initialization.

02 · Clustering

How the groups are formed

K-Means learns without labeled examples. It improves an initial grouping through repeated assignment and centroid updates.

  • Choose a dataset and K to define the numeric points and number of groups.
  • Initialize centroids randomly or with K-Means++ when using Euclidean distance.
  • Assign each point to its nearest centroid with the selected distance metric.
  • Update each centroid using the metric's mean, median or normalized-mean rule.
  • Repeat until movement is below 0.001 or 100 iterations have run.

Labels and silhouette score

Ground-truth colors are available for labeled synthetic datasets and Iris. Customer segmentation has no reference cluster labels, so its results are exploratory. The silhouette score describes cluster separation; it is not classification accuracy or proof that clusters have real-world meaning.

03 · Interaction

Learn by exploring

Compare how datasets and settings change the cluster assignments and centroid paths.

  • Choose from seven datasets, including synthetic patterns, customer segmentation, Iris measurements and image colors.
  • Change K to see how the requested number of clusters changes the grouping.
  • Compare initialization and distance options to explore different starting points and notions of similarity.
  • Start, pause, resume or restart the clustering animation.
  • Select a point to inspect its distance from each centroid.
  • Follow centroid markers and trails as centers move between iterations.
  • Compare colors with reference labels when available, or with original pixel colors for image quantization.
Ground truth depends on the dataset

Labeled synthetic datasets and Iris provide reference labels for comparison. Image color quantization can show original pixel colors. Customer segmentation has no ground-truth clusters.

04 · Technology

How this model is built

The Unity scene runs clustering over numeric coordinates and animates assignments and centroid movement.

The visualizer is implemented in Unity and C#. It supports Euclidean, Manhattan and Cosine distance, with a centroid update rule matched to each metric.

Results depend on the dataset, K, initialization and distance metric. Different settings can produce different groupings, and cluster IDs do not represent predefined classes.
